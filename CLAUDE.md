# www.panov.id — правила проекта

Статический сайт: визитка собирается из `README.md`, блог — из `content/posts/`.
Ванильный Node без зависимостей, запускается в контейнере (на хост ничего не ставится).
Публикация автоматическая при отправке изменений в `main`.

## Блог

Ведётся ассистентом. Формат, тон и словарь замен — навык `blog-post`.

- Посты только на русском. Это записанное исключение из правила парности документов.
- **Ни одного названия компании, продукта или вендора** — ни в тексте, ни в примерах кода,
  ни в заголовке. Проверяется `scripts/lint-brands.sh`, сборка падает при совпадении.
- Стандарты и протоколы брендами не считаются: RFC, OAuth, HTTP, SQL, RSS, SVG.
- Обложка генерируется из хеша заголовка, руками не рисуется.
- `feed.xml`, `blog/index.html` и страницы постов —собираются сборкой, руками не правятся.

## Сборка

```bash
./scripts/lint-brands.sh && ./scripts/build.sh
```

Порядок важен: линтер первым, иначе можно собрать и отправить текст с упоминанием.
