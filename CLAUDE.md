# www.panov.id — правила проекта

Статический сайт: визитка собирается из `README.md`, блог — из `content/posts/`.
Ванильный Node без зависимостей, запускается в контейнере (на хост ничего не ставится).
Публикация автоматическая при отправке изменений в `main`.

## Блог

Ведётся ассистентом. Формат, тон, выбор темы и порядок публикации — навык `blog-post`.

- Когда писать, решает не память, а счёт: `~/.claude/scripts/blog-due.sh` считает дни
  с последнего поста и коммиты по всем проектам группы, а хук `SessionStart` приносит
  результат в сессию. Пока порог не пройден, скрипт молчит.
- Посты только на русском. Это записанное исключение из правила парности документов.
- **Ни одного названия компании, продукта или вендора** — ни в тексте, ни в примерах кода,
  ни в заголовке. Проверяется `scripts/lint-brands.sh`, сборка падает при совпадении.
- Свои проекты — тоже бренды: домены и имена репозиториев группы в списке линтера.
- Стандарты и протоколы брендами не считаются: RFC, OAuth, HTTP, SQL, RSS, SVG.
- Обложка генерируется из хеша заголовка, руками не рисуется.
- `feed.xml`, `blog/index.html` и страницы постов —собираются сборкой, руками не правятся.

## Сборка

```bash
./scripts/lint-brands.sh && ./scripts/build.sh
```

Порядок важен: линтер первым, иначе можно собрать и отправить текст с упоминанием.

## Экономия токенов (глобальный блок, правится в ~/.claude/templates/project-rules.md)

- Шумный вывод — только через `digest`: `… 2>&1 | digest <phpunit|phpstan|cs|compose|git|httplog|auto>`.
  Печатает ≤12 строк, полный текст кладёт в scratchpad и называет путь; подробности — `sed -n` по диапазону.
  Хук `guard-long-output.py` отказывает прогону тестов, логам и полному diff без `digest`/`tail`/файла.
- Механический шаг с машинной проверкой — `haiku-runner`; модуль по спецификации — `sonnet-runner`;
  готовый diff-план — `codex exec` через обёртку (навык `delegate`). Fable — безопасность, миграции, развилка без ответа; решения и ревью — Opus.
- Прогон дольше минуты — `run_in_background`, читать итог через `digest`, не файл целиком.
- Команда длиннее 300 символов или из 4+ звеньев без скрипта — `guard-inline-command.py` сохраняет её в
  `~/.claude/state/inline/` и пускает; повторяемое — в `scripts/` или `~/.claude/scripts/bin/`, разовое — файл в scratchpad.
- Офлайн-ворота проекта — `.claude/gates.txt` (команда на строку, `watch:` — какие правки
  их запускают); после хода с правкой `gates-run.py` гонит их фоном, вердикт (rc на ворота)
  приходит со следующим промптом. Только офлайн-контейнеры — сети в фоне не бывает.
